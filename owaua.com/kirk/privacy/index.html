privacy

what it remembers

Last updated September 23, 2026. owaua keeps a short history of your chats with it, plus a few recent lines from the channel, so it can answer. This page says what that covers.

01

what this is for

This is for the official owaua Discord bot, the app you invite from this site, client id 1442127404607737999. The website and the owaua Discord server sit with the same person.

Discord has its own privacy policy, and that still applies. If you run a copy of the code yourself, that copy is yours, and you are the one responsible for it. This page is only for the official bot.

Using the bot also means you agree to the terms.

02

who to write to

owaua is a privately run Discord app. Questions, deletion requests, and anything else about this page can go to ckazros@owaua.com, Discord ckazros, or the Discord server.

Include your Discord user id if you want a specific account looked up. Please don’t paste private chats into a public channel.

03

what it collects

Only what it needs to answer you, and to remember a little of the conversation so the next reply has something to go on.

Discord ids

Your user id, and the server and channel ids when you talk in a server. Display names come along with the message Discord already sent. Server id is stored so one guild can be wiped without touching others. DMs have an empty server id.

messages

Pings and replies, plus DMs only when the operator enables them, are the conversation. In a server channel it can read, it also keeps a short recent line (display name, user id, and up to 180 characters) so a later ping can follow the room. That log is not your persona and not your private thread. Prefix commands can show up in it because they were said in the channel. Other bots are ignored. DMs are not scanned for anyone else’s chatter.

attachments

Gemini hangout can look at one image. Other normal-mode providers stay text-only. Audio attachments can be used by !music within its safety limits.

channel and server settings

The selected persona, reply language, and provider choice. Those live in the same SQLite file so they survive a restart. Public DMs are off by default.

usage limits

A usage record marks each AI request so the same Discord event is never answered twice. The running process allows eight AI-admission attempts per user per minute, and up to three AI users can be in flight. Command cooldowns are separate.

voice and music

!music sees the author’s voice channel and a single YouTube or Twitter/X video link, or a supported audio attachment. Ordinary playback is capped at 15 minutes and 20 MiB where downloaded audio is involved. The current track is not saved across restarts, and playlists are rejected.

mail you send us

If you email or DM the operator, that message is just a message. We keep what we need to answer it.

It still does not reply unless pinged. It does keep those short channel lines from channels it can read. Other bots are ignored.

04

why it keeps any of this

So it can reply, remember the last few turns, and know a little of the room. So it keeps the persona and language you asked for. So one person can’t melt it. So it can play a song you asked for.

We don’t sell this. There are no ads. Your DMs are not a mailing list.

05

how memory works

Data lives in a local SQLite file on the host (data/memory.sqlite3, WAL mode). Each conversation is keyed by channel + user. Two people in the same channel have separate histories and separate personas. The same person in two channels has two histories. Up to 12 of the last 20 records in your thread can go back to the model, with inputs capped at 2,000 characters. Up to 12 recent channel lines can go with that reply, as untrusted room context. The channel log keeps at most 40 lines per channel.

There is no privacy opt-in gate: the recent chat is stored because the bot needs it to talk. Threads and channel lines are pruned after seven days. A thread also falls off beyond 20 records, and the message table tops out at 10,000 records. Duplicate Discord events for the same message id are not stored twice.

Please don’t send passwords, tokens, private keys, or anything you would not want saved. If you already did, have someone with Manage Server run !memory erase in that server, or write us.

06

who else sees it

Discord already has the message. That is their platform, their rules.

To generate a reply, the bot sends the current prompt and, when conversation context is useful, up to the last 12 stored messages for that channel + user, plus up to 12 recent channel lines, to the configured model provider. Gemini 3.1 Flash Lite hangout requests can include one image attachment; other normal-mode providers remain text-only. Approved full-mode requests can also include one image attachment and do not include the channel-line block. Provider-side storage is requested off. A local self-harm check and other refusal guards can answer without calling the model at all.

Other services only see what that feature needs:

music

The supported link or attachment metadata needed to resolve and play one track. Music commands are written to a restricted audit log with Discord/user/server/channel metadata, the requested action, a hash of the raw argument, and the outcome; signed media URLs are not written.

We are not Discord, and we are not those vendors. Their policies apply to what passes through them. There is no TTS provider, no speech-to-text, and no third-party antivirus scan.

07

how long it stays

Recent conversation stays until it falls off the 20-record-per-conversation window, expires after seven days, until an erase command wipes it, or until we delete it for you. Channel lines stay until they fall off the 40-line channel window, expire after seven days, or an erase command wipes them. Persona, language, and provider settings stay until they are changed.

The eight-per-minute counters live in memory and disappear when the process restarts. A usage record for each AI request stays in the same SQLite file so the same Discord event is not answered twice. The current music track is not kept as conversation history.

Backups of the host can hold a copy of the SQLite file for as long as those backups exist. Treat that file like private chat, because it is.

08

your choices

If you don’t want a record, don’t talk to it. Leaving a server stops new server memory for you there. It does not, by itself, wipe what is already stored.

There is no per-user export command. You can run !memory erase mine to delete your own thread and your channel lines, including short copies of replies that were to you. Someone with Manage Server can run !memory erase to delete every stored conversation and channel line for that server. That does not erase other servers, DMs, or settings such as persona, language, or provider choice.

If that is not enough, email ckazros@owaua.com with the Discord user id. Say whether you mean DMs, a server, or both. Discord messages in the channel itself are Discord’s, not ours.

You can also stop using the bot, kick it from a server, or close your Discord account. Kicking it stops new collection in that server. It does not automatically purge the SQLite file.

09

this website

The site is static pages. This edition does not set cookies and does not load a third-party tag. The pages at the root of owaua.com load Pinterest’s conversion and audience tag. Pinterest may receive page-view and device information under its own privacy policy; no email address or enhanced-match data is sent by that site.

The host and the browser still do normal web things: a request log on their side, a cached file on yours. We do not use that to profile you. Contact is just email.

10

age

You need a Discord account, and you need to be old enough for Discord. That means 13 or older. Please don’t use the bot if you are under 13.

All personas are intended for general-audience Discord servers. The bot does not provide adult-content modes.

11

the official bot vs running it yourself

Self-hosting means your SQLite file, your keys, your users, and your own privacy policy. The official bot is the one invited from this site.

We can change models, limits, and where the file lives. If that changes what we collect in a way that matters, this page will say so.

12

if this page changes

If this page changes, the new text applies once it is up. The date at the top is when that happened. Keeping the bot after that is agreement to the new policy.

Questions go to ckazros@owaua.com, Discord ckazros, or the Discord server.
