# Security

Please report a vulnerability in private. A public issue is a bad place for a token, a working exploit, or someone else's messages.

Use the Security tab on this repository and choose Report a vulnerability. Say what is affected, what someone could do with it, and a short way to reproduce it. Leave out live tokens, `.env` values, private conversations, and database files.

There is no bounty. Give the report a little time before you describe it in public.

If you run your own copy, keep `.env` and `data/` where other people cannot read them, and give the Discord bot only the permissions it needs. Prompts and attachments go to xAI, and to Jiki if you configured it. Do not send that bot secrets you would not want those services to store.

The local health ports are for the machine running the bot. Do not publish them to the internet.
